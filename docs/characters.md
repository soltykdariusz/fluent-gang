# Fluent Gang Characters

Fluent Gang should have its own small cast of characters. They should make the app feel warmer, more memorable, and less technical without making it childish.

The goal is not to copy Duolingo. The inspiration is the strategic use of characters: emotional presence, guidance, small celebrations, and a recognizable product world.

## Character Direction

Fluent Gang characters should feel:

- premium but approachable
- funny but not childish
- expressive but not noisy
- simple enough to animate
- visually consistent with the green Fluent Gang identity
- useful inside learning moments, not just decorative

They should appear where they add motivation, clarity, or delight:

- after a correct answer
- after finishing a word
- during Super Memory mode
- during shadowing
- inside focus milestones
- inside game mode
- on empty states and progress screens

## Visual Style

Early direction:

- small character illustrations or SVG-based mascots
- simple geometric shapes
- soft silhouettes
- restrained premium palette built around Fluent Gang green
- expressive eyes and posture
- subtle line work or clean flat shapes
- small looping or one-shot animations
- no loud arcade aesthetic
- no overly childish sticker style

Characters should share a common visual DNA:

- similar eye language
- similar proportions
- consistent outline or no-outline style
- consistent shadow/highlight rules
- consistent hand/foot style if humanoid
- consistent use of green accents

## First Character Cast

### The Mentor

Role: calm guide.

Appears in:

- onboarding
- learning guide
- progress reflections
- difficult moments

Personality:

- calm
- concise
- confident
- slightly elegant

Example voice:

- "Small steps. Strong memory."
- "Read the scene first. The word will land."
- "You are building fluency, not chasing it."

### The Hype Friend

Role: energy and celebration.

Appears in:

- correct quiz answers
- streaks
- completed lessons
- game wins

Personality:

- warm
- excited
- playful
- never annoying

Example voice:

- "That one clicked."
- "Clean answer."
- "Your gang approves."

### The Memory Freak

Role: Super Memory storyteller.

Appears in:

- Super Memory mode
- absurd story generation
- memory tips

Personality:

- vivid
- strange
- theatrical
- funny

Example voice:

- "Make it weird. Weird sticks."
- "If the image feels ridiculous, perfect."
- "Your brain remembers scenes, not lists."

### The Shadow Coach

Role: speaking and rhythm coach.

Appears in:

- shadowing
- listening
- future pronunciation feedback

Personality:

- precise
- encouraging
- rhythmic
- focused

Example voice:

- "Match the rhythm first."
- "Slower is still progress."
- "Now say it like you mean it."

### The Rival

Role: friendly challenge.

Appears in:

- game mode
- leaderboards
- weekly challenges
- group competition

Personality:

- witty
- competitive
- teasing but kind

Example voice:

- "Not bad. I expected almost that."
- "One more round?"
- "Your streak is starting to look dangerous."

## Usage Rules

- Characters should support the learning moment.
- Do not place characters on every screen by default.
- Do not let characters cover core content.
- Do not use big character art where the user needs dense information.
- Use small reactions and micro-animations more often than large illustrations.
- In premium/productivity screens, characters should feel like tasteful companions, not mascots screaming for attention.

## Animation Rules

Animations should be:

- silent
- short
- subtle
- meaningful
- skippable by flow
- never blocking progress

Good animation moments:

- correct answer
- 5-minute focus milestone
- lesson complete
- game round complete
- first word remembered
- review streak maintained

Avoid:

- constant idle motion
- large bouncing effects
- excessive confetti
- interrupting reading
- animation after every tiny tap

## Product Integration

### Core Learning

Use characters lightly:

- Mentor introduces a learning stage.
- Hype Friend reacts after a quiz step.
- Shadow Coach appears in shadowing.

### Super Memory

Use characters more strongly:

- Memory Freak can introduce the absurd story.
- Visuals can be more vivid and funny.

### Game Mode

Use characters most playfully:

- Rival hosts competitive rounds.
- Hype Friend celebrates funny answers.
- Group mode can show small character badges for players.

### Progress

Use characters reflectively:

- Mentor comments on weekly progress.
- Rival can appear in challenges.
