# Fluent Gang Mascot Direction

Reference image:

`assets/reference/gangImg.png`

This image is a concept board for the Fluent Gang character direction. It is not treated as final runtime art yet.

## Direction

The characters should make the app feel more alive, friendly, motivating, and less technical.

The style can include:

- premium streetwear energy
- expressive but not childish characters
- clear emotional states
- clean mobile-friendly silhouettes
- strong Fluent Gang green accents
- speech bubbles and short coaching messages

## Current Character Roles

- Chameleon: main guide, adaptation, context, vocabulary growth
- Tiger: focus, strength, discipline
- Parrot: speaking, shadowing, repetition
- Panda: calm review, consistency
- Fox: clever memory hooks and flexible thinking

## Final Art Notes

The current reference is intentionally energetic and expressive. Future production assets should be slightly calmer, cleaner, and more mobile-friendly.

Goals:

- keep personality
- reduce visual noise
- simplify details for small screens
- support Lottie states
- support static fallback PNG/WebP

## Mascot States

The app currently supports:

- idle
- thinking
- happy
- oops
- celebrate
- encourage

Future animation files can be connected through `src/constants/mascotAnimations.ts`.
